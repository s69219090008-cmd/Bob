บทที่ 1

พื้นฐานและกระบวนการทำงานของเว็บไซต์

1. ความหมายและองค์ประกอบหลักของเว็บ (Website & Technology)
  • องค์ประกอบหลักของเว็บ เปรียบเทียบได้กับ "หนังสือหนึ่งเล่ม"

Web Page: หน้ากระดาษแต่ละหน้า บรรจุเนื้อหาเฉพาะเรื่อง.

Website: หนังสือทั้งเล่ม ที่รวม Web Page หลายหน้าเข้าด้วยกัน.

Home Page: หน้าปกหนังสือ เป็นหน้าแรกสุดที่ผู้ใช้จะพบเห็นเสมอ.

  • Web Browser: ทำหน้าที่เป็น "ผู้แปลภาษาสากล" หรือวิศวกรที่นำโค้ดที่ซับซ้อน (HTML, CSS, JavaScript) มาประมวลผลและเนรมิตให้เป็นหน้าเว็บไซต์จริงที่สวยงาม
  • ประเภทเทคโนโลยีเว็บไซต์ แบ่งออกเป็น 2 ประเภทหลัก

1.Static Website: เนื้อหาคงที่เหมือนใบปลิว ทำง่าย โหลดเร็ว ปลอดภัยสูง แต่แก้ไขข้อมูลยากเพราะต้องแก้ที่โค้ดทีละหน้า เหมาะกับ Portfolio หรือเว็บที่ข้อมูลไม่เปลี่ยนบ่อย.

2.Dynamic Website: เนื้อหาเปลี่ยนตามฐานข้อมูลและการโต้ตอบของผู้ใช้ ยืดหยุ่นกว่าและมีค่าใช้จ่ายเรื่อง Server แต่จัดการข้อมูลจำนวนมากได้ง่าย เหมาะกับร้านค้าออนไลน์ (E-commerce) หรือโซเชียลมีเดีย.

2. กระบวนการทำงานของเว็บไซต์ (Client-Server Model) กระบวนการรับ-ส่งข้อมูลเปรียบเหมือนการสั่งอาหารในร้าน
  • ใช้ระบบ Client-Server
  • Client (Browser) ส่งคำขอ (Request)
  • Server ประมวลผลข้อมูล
  • Server ส่งข้อมูลกลับ (Response)
  • Browser แสดงผลหน้าเว็บ (Render)
3.หลักการทำงานของ WWW
  • URL ใช้ระบุตำแหน่งเว็บไซต์
  • HTTP โปรโตคอลรับส่งข้อมูลทั่วไป
  • HTTPS โปรโตคอลที่มีการเข้ารหัสข้อมูล ปลอดภัยกว่า HTTP
  • IP Address คือหมายเลขประจำเครื่องบนอินเทอร์เน็ต
  • Domain Name คือชื่อเว็บไซต์ที่จำง่าย เช่น google.com
  • DNS แปลง Domain Name เป็น IP Address
4.การวางแผนโครงสร้างเว็บไซต์
  • Site Map แสดงโครงสร้างและลำดับหน้าต่าง ๆ ของเว็บไซต์
  • Navigation Flow กำหนดเส้นทางการใช้งานภายในเว็บไซต์
  • กฎ 3 คลิก (3-Click Rule) ผู้ใช้ควรเข้าถึงข้อมูลที่ต้องการได้ภายในไม่เกิน 3 คลิก
5.เครื่องมือพัฒนาเว็บไซต์
  • ใช้โปรแกรม Visual Studio Code (VS Code) สำหรับเขียนโค้ด

ส่วนขยายที่แนะนำ ได้แก่

  • Live Server, Live Preview, Thunder Client
  • Prettier, Error Lens, Code Spell Checker
  • Auto Rename Tag, Auto Close Tag, HTML CSS Support
