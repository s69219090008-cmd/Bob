การจัดรูปแบบเว็บไซต์ด้วย CSS

1. วิธีการเชื่อมต่อ CSS
  • Internal CSS : เขียน CSS ไว้ภายในไฟล์ HTML ในแท็ก <style> เหมาะกับเว็บขนาดเล็ก
  • External CSS : แยก CSS เป็นไฟล์ .css แล้วเชื่อมต่อด้วยแท็ก <link> เหมาะกับเว็บไซต์หลายหน้าและเป็นมาตรฐานที่นิยมใช้
2. CSS Selectors ใช้เลือกองค์ประกอบที่ต้องการตกแต่ง
  • Tag Selector เช่น h1, p
  • Class Selector ใช้เครื่องหมาย . เช่น .menu
  • ID Selector ใช้เครื่องหมาย # เช่น #header และห้ามซ้ำในหน้าเดียว
3. ระบบ Box Model องค์ประกอบทุกชิ้นบนเว็บถูกมองเป็น "กล่อง" ประกอบด้วย
  • Content เนื้อหาภายใน
  • Padding ระยะห่างภายในกล่อง
  • Border เส้นขอบกล่อง
  • Margin ระยะห่างภายนอกกล่อง
  • Width / Height กำหนดขนาดความกว้างและความสูงของกล่อง
Content
4. การจัดตำแหน่ง (Layout Positioning) Display
  • block แสดงเต็มบรรทัด
  • inline แสดงต่อกันในบรรทัดเดียว
  • flex จัดวางองค์ประกอบได้ยืดหยุ่นและเป็นระเบียบ

Position

  • relative เลื่อนจากตำแหน่งเดิม
  • absolute กำหนดตำแหน่งอิสระภายในกล่องแม่
  • fixed ยึดติดกับหน้าจอแม้เลื่อนหน้าเว็บ
