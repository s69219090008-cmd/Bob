บทที่ 8

การออกแบบและสร้างฟอร์ม (Forms)

8.1 องค์ประกอบของฟอร์ม
<form>
action="..."
GET
POST
  • ใช้แท็กคู่ <form> เป็น "ซองจดหมาย" บรรจุช่องกรอกข้อมูลทั้งหมด
  • action : ระบุ URL ปลายทางที่จะรับข้อมูลไปประมวลผล
  • method="GET" : ส่งข้อมูลแนบท้าย URL เห็นได้ชัดเจน เหมาะกับข้อมูลทั่วไป
  • method="POST" : ซ่อนข้อมูลไว้เบื้องหลัง เหมาะกับข้อมูลส่วนตัว/รหัสผ่าน
  • จับคู่ <label for="..."> กับ <input id="..."> เพื่อคลิกป้ายแล้วเคอร์เซอร์กระโดดเข้าช่องกรอกทันที
8.2 ประเภทของ Input
Text : ชื่อ-นามสกุล
Password : • • • • • •
Email : name@mail.com
Radio : เลือกได้ข้อเดียว
✓
Checkbox : เลือกได้หลายข้อ
Select : จังหวัด ▾
  • Text / Password / Email : ช่องกรอกข้อความ เปลี่ยนพฤติกรรมตามค่า type
  • Radio : บังคับเลือกได้เพียงข้อเดียว เหมาะกับคำถามคำตอบเดียว เช่น เพศ
  • Checkbox : เลือกได้หลายข้อหรือไม่เลือกเลยก็ได้ เช่น งานอดิเรก
  • Select/Option : เมนูแบบเลื่อนลง เหมาะกับตัวเลือกจำนวนมาก ช่วยประหยัดพื้นที่
  • เลือกประเภทให้ถูกฝาถูกตัว ช่วยลด Human Error และเพิ่มความถูกต้องของข้อมูล
8.3 การตรวจสอบข้อมูล (Validation)
🚫 ข้อมูลไม่ผ่านเงื่อนไข
ระงับการส่งฟอร์ม
required
min
max
  • required — บังคับกรอกข้อมูล ห้ามเว้นว่าง เหมือนดอกจันสีแดง (*)
  • min / max — กำหนดขอบเขตต่ำสุด-สูงสุด ใช้กับตัวเลขหรือวันที่
  • HTML5 มีระบบ Built-in Form Validation ตรวจสอบอัตโนมัติในตัวเบราว์เซอร์
  • หากข้อมูลผิดเงื่อนไข ระบบจะไม่ยอมส่งฟอร์มและแจ้งเตือนผู้ใช้งานทันที
ตัวอย่างการปฏิบัติ: สร้างฟอร์มที่เชื่อมโยง label กับ input พร้อม Validation

ใช้ <label for> คู่กับ <input id> และเติมแอตทริบิวต์ required เพื่อบังคับกรอกข้อมูลก่อนส่งฟอร์ม

<form action="submit.php" method="post">
  <label for="uname">ชื่อผู้ใช้:</label>
  <input type="text" id="uname" required>

  <label for="age">อายุ:</label>
  <input type="number" id="age" min="18" max="60">

  <button type="submit">ส่งข้อมูล</button>
</form>
สรุปท้ายบท

บทนี้ว่าด้วยการออกแบบและสร้างฟอร์ม (Forms) ซึ่งเปลี่ยนเว็บไซต์จากการสื่อสารทางเดียวให้กลายเป็น การสื่อสารสองทาง (Two-way Communication) โดยใช้แท็ก <form> เป็นพื้นที่บรรจุข้อมูล พร้อมแอตทริบิวต์ action และ method (GET/POST) เป็นตัวกำหนดปลายทางและวิธีจัดส่งข้อมูล จากนั้นใช้แท็ก <input> ร่วมกับ <label> ในการรับข้อมูลหลากหลายรูปแบบ ทั้งกลุ่มข้อความ (Text, Password, Email) และกลุ่มตัวเลือก (Radio, Checkbox, Select) สุดท้ายใช้ระบบตรวจสอบข้อมูล อัตโนมัติของ HTML5 (Built-in Form Validation) ผ่านแอตทริบิวต์ required, min และ max เพื่อดักจับและป้องกันข้อมูลผิดพลาดก่อนส่งออกไปยังเซิร์ฟเวอร์ ก่อนก้าวเข้าสู่บทถัดไปเรื่อง "ภาษา JavaScript"
