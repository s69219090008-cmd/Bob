Absolute Path (ภายนอก)
  • ใช้แท็กคู่ <a> (Anchor) เพื่อสร้างการเชื่อมโยง
  • ต้องใส่แอตทริบิวต์ href เสมอ เพื่อระบุปลายทาง
  • เชื่อมโยงภายใน : ใช้ Relative Path เช่น href="about.html"
  • เชื่อมโยงภายนอก : ใช้ Absolute Path ขึ้นต้นด้วย https:// เสมอ
7.2 เทคนิคการเชื่อมโยง

Anchor Link

  • target="_blank" : เปิดลิงก์ในแท็บใหม่ โดยไม่ปิดหน้าเว็บเดิม
  • Anchor Link : สร้างจุดหมายด้วย id แล้วกระโดดด้วย href="#id"
  • ช่วยยกระดับประสบการณ์ผู้ใช้งาน (UX) ให้ลื่นไหลขึ้น
7.3 การปรับแต่งลิงก์ด้วย CSS (Link States)
:link
:visited
:hover
:active
  • :link — สถานะปกติ ยังไม่เคยถูกคลิก
  • :visited — เคยคลิกไปแล้ว เบราว์เซอร์เปลี่ยนสี (มักเป็นสีม่วง)
  • :hover — ขณะนำเมาส์ไปวางบนลิงก์
  • :active — เสี้ยววินาทีขณะกำลังกดเมาส์ค้าง
  • ใช้ Pseudo-class ควบคุมแต่ละสถานะแยกจากกันได้อย่างอิสระ
ตัวอย่างการปฏิบัติ: เนรมิตข้อความลิงก์ให้เป็นปุ่มกด

ใช้ CSS ลบเส้นใต้ ใส่พื้นหลัง และมุมโค้ง เพื่อแปลงลิงก์ธรรมดาให้กลายเป็นปุ่มกดสวยงาม

<a href="contact.html" class="btn">ติดต่อเรา</a>

/* CSS */
.btn {
  text-decoration: none;
  background: #EE3355;
  color: white;
  padding: 12px 26px;
  border-radius: 30px;
}
.btn:hover { background: #c81f42; }

สรุปท้ายบท

บทนี้ว่าด้วยระบบการเชื่อมโยง (Hyperlinks) ซึ่งเป็นหัวใจของ "World Wide Web" โดยใช้แท็ก <a> คู่กับแอตทริบิวต์ href เป็นตัวระบุปลายทาง แยกเป็น Relative Path สำหรับเชื่อมโยงภายในเว็บไซต์เดียวกัน และ Absolute Path สำหรับเว็บไซต์ภายนอก พร้อมทั้งควบคุมพฤติกรรมการคลิกด้วย target="_blank" และสร้าง Anchor Link เพื่อกระโดดข้ามเนื้อหาในหน้าเดียวกัน สุดท้ายใช้ CSS ผ่าน Pseudo-class ทั้ง 4 สถานะ (:link :visited :hover :active) เพื่อตกแต่งลิงก์ให้กลมกลืนกับธีมเว็บไซต์ ก่อนก้าวเข้าสู่บทถัดไปเรื่อง "แบบฟอร์ม (Forms)"
