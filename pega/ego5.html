บทที่ 5

การจัดการข้อความและสื่อมัลติมีเดีย

5.1 การจัดการข้อความระดับสูง
color / font-size
Aa
Aa
Aa
  • ใช้คำสั่ง color กำหนดสีข้อความ (ชื่อสี, Hex Code, RGB)
  • ใช้คำสั่ง font-size กำหนดขนาดตัวอักษร (นิยมหน่วยพิกเซล px)
  • ควรออกแบบตาม Visual Hierarchy หัวข้อใหญ่ เนื้อหาเล็กแต่อ่านง่าย
  • เชื่อมต่อ Google Fonts ผ่านแท็ก <link> แล้วเรียกใช้ด้วย font-family
5.2 การแทรกรูปภาพและสื่อ
<img src="">
Absolute Path https://...
Relative Path images/...
  • ใช้แท็กเดี่ยว <img> คู่กับแอตทริบิวต์ src เพื่อระบุที่อยู่ไฟล์ภาพ
  • Absolute Path : ชี้ไปยังรูปภาพบนเว็บไซต์อื่น (ขึ้นต้นด้วย http/https)
  • Relative Path : อ้างอิงจากโฟลเดอร์โปรเจกต์ตัวเอง เป็นมาตรฐานมืออาชีพ
  • ควรบีบอัด/ย่อขนาดภาพ (Image Optimization) เพื่อให้เว็บโหลดเร็วและ SEO ดี
5.3 การจัดการวิดีโอและเสียง
🔊
  • แท็ก <video> สำหรับวิดีโอ และ <audio> สำหรับเสียง
  • ต้องมีแอตทริบิวต์ src ระบุไฟล์ (เช่น .mp4)
  • แอตทริบิวต์ controls คือหัวใจสำคัญ ทำให้เกิดแผงควบคุมเล่น/หยุด
5.4 การสร้างเฟรมด้วย Inline Frame (Iframe)
<iframe src="">
  • <iframe> ใช้ "เจาะหน้าต่าง" ดึงหน้าเว็บอื่นมาแสดงในเว็บของเรา
  • src : URL ปลายทาง (ต้องเป็น Absolute Path https://)
  • width / height : กำหนดขนาดกรอบเฟรม
  • title : คำอธิบายเฟรม สำคัญต่อ Screen Reader
  • allowfullscreen : อนุญาตให้ขยายเต็มจอ
  • นิยมใช้ฝังวิดีโอ YouTube และแผนที่ Google Maps
สรุปท้ายบท

บทนี้เชื่อมโยงการตกแต่งข้อความด้วย CSS และ Google Fonts เข้ากับการแทรกสื่อมัลติมีเดีย ทั้งรูปภาพ (<img> + src), วิดีโอ/เสียง (<video>/<audio> + controls) และการฝังเนื้อหาจากภายนอกด้วย <iframe> ทำให้เว็บไซต์ดูเป็นมืออาชีพ โหลดเร็ว และมีปฏิสัมพันธ์กับผู้ใช้งานได้ดียิ่งขึ้น ก่อนก้าวเข้าสู่บทถัดไปเรื่อง "การสร้างตารางข้อมูล (Tables)"
