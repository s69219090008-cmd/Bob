การสร้างเว็บไซต์ด้วย HTML5

1. โครงสร้างมาตรฐานของ HTML5 ประกอบด้วย 3 ส่วนหลัก
  • <!DOCTYPE html> ประกาศว่าใช้มาตรฐาน HTML5
  • <head> เก็บข้อมูลเบื้องหลัง เช่น ชื่อหน้าเว็บ (<title>) และการตั้งค่าต่าง ๆ
  • <body> เป็นส่วนแสดงเนื้อหาที่ผู้ใช้มองเห็นบนหน้าเว็บ
2. การใช้งาน Tag และ Attribute

Tag คือคำสั่งที่ใช้กำหนดรูปแบบและโครงสร้างของข้อมูล

Attribute คือคุณสมบัติเสริมที่เพิ่มรายละเอียดให้แท็ก เช่น สี ขนาด หรือลิงก์ต่าง ๆ

3. การจัดการข้อความ
  • ใช้แท็ก <h1> ถึง <h6> สำหรับหัวข้อ โดย <h1> สำคัญที่สุดและควรมีเพียง 1 ตัวต่อหน้าเว็บ
  • ใช้ <p> สำหรับย่อหน้า
  • ใช้ <br> เพื่อขึ้นบรรทัดใหม่ภายในข้อความ
4. การสร้างรายการข้อมูล (Lists)
  • <ul> รายการแบบไม่มีลำดับ (Bullet)
  • <ol> รายการแบบมีลำดับ (ตัวเลขหรือตัวอักษร)
  • <li> ใช้กำหนดแต่ละรายการ
5. การใช้ Extensions ใน VS Code ส่วนขยายช่วยให้เขียนโค้ดได้รวดเร็วและลดข้อผิดพลาด เช่น
  • Prettier จัดรูปแบบโค้ดอัตโนมัติ
  • Error Lens แสดงข้อผิดพลาดทันที
  • Auto Rename Tag เปลี่ยนชื่อแท็กเปิด-ปิดพร้อมกัน
  • Auto Close Tag เติมแท็กปิดอัตโนมัติ
  • Live Server แสดงผลเว็บไซต์แบบเรียลไทม์และจำลองการทำงานของเว็บเซิร์ฟเวอร์จริง
